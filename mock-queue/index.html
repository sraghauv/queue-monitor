Test Parameters

Control behavior with query string parameters:

  • ?start=N — Initial value (default: 10)
  • ?step=N — Increment per tick (default: 1)
  • ?interval=MS — Tick interval in milliseconds (default: 2000)
  • ?mode=normal|stall|disappear|slow — Behavior mode
  • ?seed=N — Offset start value for multi-tab testing

Modes:
normal — Advances continuously until max
stall — Stops advancing after a few ticks (tests stale readings)
disappear — Removes the progress element after ~10s (tests recovery from missing element)
slow — Uses a 10s tick interval instead of default
