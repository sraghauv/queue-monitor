# Disclaimer

**Authorized use only.** Only point this extension at queue pages you are authorized to monitor.

**Opening more tabs does not guarantee independent queue entries.** Multiple tabs may share the
same queue or session identity on the site you're monitoring, and this extension has no way to
know whether they do. Do not assume that N tabs means N independent positions in line, and be
aware that opening many tabs against a site may violate that site's terms of service.

**This tool contains no capability to bypass waiting rooms, CAPTCHAs, bot detection, or rate
limits**, and none will be added. If a site puts up one of these barriers, this extension will
not get through it.

**The score shown is not a probability.** It is a ratio against the best progress this extension
has observed among the tabs you opened, in this session. Score 100 means "the best progress
observed so far," not "100% chance of getting through," and not any estimate of your odds of
getting tickets, seats, or anything else.

**Respect the terms of any site you monitor, and get permission where required.** This tool does
not know or enforce any site's terms on your behalf — that responsibility is yours.

**No warranty.** The authors provide this software with no warranty of any kind. The operator —
whoever runs this extension — is responsible for how they use it and for the consequences of that
use.

**Independent implementation.** This project was built independently from a public description
of a feature set and contains no third-party proprietary code.
